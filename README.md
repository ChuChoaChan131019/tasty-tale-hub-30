# Culinary Canvas

Create a complete, modern, and fully responsive web application for a 'Culinary Blog' using React, Tailwind CSS, Lucide icons, and TypeScript. The UI should use a warm, appetizing color palette (warm amber, emerald green accents, clean neutral backgrounds). The application must include the following key views/sections that you can navigate or scroll through:

Global Layout:

A responsive Navbar with Logo ('Culinary Blog'), links to Home, Recipes, Categories, a Search bar, and a User profile menu.

A clean Footer with quick links and copyright.

Home Page (/):

Hero Section with a catchy cooking headline and a prominent search bar.

Categories Grid showing popular food categories with icons and recipe counts.

Featured Recipes Grid with cards displaying recipe images, titles, author, difficulty badge, cook time, and category tags.

Recipe Detail Page (/recipes/[slug]):

Full view of a recipe including large hero image, title, author info, prep/cook time, servings, and difficulty.

Ingredients checklist section with quantities and units.

Step-by-step instructions with step numbers, descriptions, and durations.

Nutrition facts box (calories, protein, carbs, fat).

Recipe Creation Form / Dashboard (/dashboard/recipes/new):

A form for authors to create a recipe: Basic info inputs (Title, Description, Category, Times, Difficulty).

Dynamic lists to add/remove Ingredients (Name, Quantity, Unit) and Steps.

Drag-and-drop image upload area with preview.

Action buttons: 'Save Draft' and 'Publish'.

Make sure the design is clean, polished, mobile-friendly, and uses realistic mock data for all cooking content.
